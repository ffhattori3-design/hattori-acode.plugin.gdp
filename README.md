# GitHub Dark Pro (Acode Plugin)

github dark pro theme for Acode Editor with dynamic matching brackets highlighting and clean UI colors.

---

## ✨ Features

- GitHub Dark + inspired color palette
- Clean syntax highlighting for all languages
- Separate colors for:
  - Keywords
  - Strings
  - Numbers
  - Functions
  - Comments (italic style)
  - Brackets & Braces
- Dark UI optimized for long coding sessions
- Lightweight and fast theme

---

## 🎨 Color Palette

- Background: #0d1117
- Foreground: #ffffff
- Keywords: #ff7b72
- Strings: #a5d6ff
- Numbers: #79c0ff
- Comments: #8b949e (italic)
- Functions: #d2a8ff
- Types: #7bec42ff
- Operators: #ff7b72
- Brackets: 
     - () : #ffffff6d
     - {} : #ffffff6d
     - [] : #ffffff6d

---

## 📦 Installation

1. Open Acode Editor
2. Go to Plugins section
3. Install this theme plugin
4. Enable "GitHub Dark Pro" from plugin section

---

## ⚙️ Requirements

- Acode Editor (latest version recommended)

---

## 🚀 Usage

After installation:

- Go to Settings
- Select Editor Theme
- Choose "GitHub Dark Pro"

---

## 🧠 Notes

- Bracket colors are styled using CodeMirror 6 highlighting system
- Comments are displayed in italic style for better readability
